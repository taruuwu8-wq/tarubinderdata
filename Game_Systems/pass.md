## ตอบให้ก่อน

ได้ Pass XP จากไหนฆ่ามอน +1 · Gathering +1 · Craft +3 ต่อครั้ง (จากกิจกรรมได้วันละไม่เกิน 600 XP) + ภารกิจรายวัน / รายสัปดาห์ / ประจำซีซัน (ไม่นับเพดานรายวัน)Hero Pass คืออะไรลู่รางวัลที่ 2 (Hero Pass) 1,090 เพชร · ซื้อแล้วรับย้อนหลังได้ทุก Tier · คนละอย่างกับสมาชิก Premiumข้าม Tier ได้ไหมได้ Tier ละ 200 เพชร (10 Tier 1,900 เพชร) ถึง Tier 50ซีซันจบแล้วได้ XP / ซื้อ Hero Pass ไม่ได้แล้ว · รางวัลที่ถึงแล้วยังกดรับได้ล็อกอินรายวันปฏิทินตามวันจริง: เข้าเกมวันไหนได้ของขวัญวันนั้น (ส่งเข้าจดหมาย) · เสาร์-อาทิตย์ของดีกว่า · วันสุดท้ายของเดือนของใหญ่สุด · วันที่ไม่เข้าก็แค่พลาดวันนั้น · ตัดรอบเที่ยงคืนเวลาไทย · ของเท่ากันทุกคน
