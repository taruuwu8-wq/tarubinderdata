# Farming and build reference refresh — 2026-11-18

## Use these sources first

- `Raw/Snapshots/2026-11-18/`: complete Firecrawl response per requested URL, including capture time, HTTP status and credits.
- `Structured_Data/farming-2026-11-18.json`: 79 maps. 62 maps publish monster population tables; the other 17 have unknown population, not zero.
- `Structured_Data/references-2026-11-18.json`: indexed skill, system, pet, material and monster pages. Select a matching record instead of reading the entire collection.
- `Raw/Snapshots/2026-11-18/tools__build-data.json.json`: latest complete Build data payload in `rawHtml` (JSON), including 318 skills, 229 monsters, 2,049 items and 79 maps.
- `buildapp-source.json` and `tools__chunk-O5MFH2SQ.js.json`: archived Build calculator JavaScript and its only static module dependency. Read as reference; these have not been ported into or validated against a complete local DPS engine.

## Website

The private Build Lab adds `/farm.html`: target monster family, minimum monster level, soul-seal threshold, three-map comparison, monster details, and actual farm result recording. Results share the existing per-owner party database and use revision checks to avoid overwriting changes from another window. No production build, card inventory or farm records were changed by the QA run.

`lookup_binder_data` now accepts `systems` and `pets`, returns captured detailed skill references, and includes population data for map detail requests. Existing older monster/card detail fields retain an explicit legacy date. Do not treat legacy fields as fresh just because the base Build payload is newer.

## Limits

- Map population is not kills/hour or density per unit area.
- Respawn time and spawn coordinates are unknown in the captured map pages.
- Monster rewards and HP are shown at the source reference level, before build, night, party or seal adjustments.
- No simulated hourly farming return has been invented. Actual runs are entered separately by the user.
- The local calculation tool still calculates raw hit damage only. Full rotation DPS, proc interaction and survivability simulation remain separate implementation work.
- Existing November 16 monster details are reused with their dates; the remaining 147 monsters are refreshed in this round.

## Reproduce website data

Run `node Tools/build_farm_data.mjs <output.json>` and `node Tools/export_site_references.mjs <output.json>`. Preserve historical raw captures and player inventory files.
