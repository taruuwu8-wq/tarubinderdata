## ตอบให้ก่อน

Focusedของที่มี Affix 1 บรรทัด ค่า ×1.8 · 2 บรรทัด ×1.35 (ไม่เกินค่าสูงสุดของ Tier ที่แสดง)มือเดียว / สองมือ

- อาวุธที่ถือคู่ได้ (Dagger / Axe / Knuckles): ทุกอาชีพที่ถือมือหลักได้ ถือมือรองได้ด้วย · อาวุธที่มือรองนับ ATK และ Affix 50%
- Dagger · มือหลัก: Rogue · มือรอง: Rogue, Scout
- Axe · มือหลัก: Warrior, Knight · มือรอง: Warrior, Knight
- Knuckles · มือหลัก: Warrior · มือรอง: Warrior
- Scout ถือ Dagger ได้เฉพาะมือรอง (Grip Skirmisher: หน้าไม้มือ + Dagger) — มือหลักของอาชีพนี้เป็นอาวุธยิง
- อาวุธสองมือ (Greatsword / Pike / Flail / Greatstaff / Spellstaff / Maul / Light Staff / Scythe): ช่องมือรองต้องว่าง · Bow / Crossbow ถือมือเดียวแต่มือรองใส่ได้เฉพาะ Quiver · ใส่ของมือรองตอนถืออาวุธสองมือ = อาวุธสองมือกลับเข้ากระเป๋า
- แลกกับพลังฐานที่สูงกว่า (Tier เดียวกัน เทียบอาวุธมือเดียวที่แรงสุดของอาชีพเดียวกัน): Greatsword +56% · Pike +51% · Flail +45% · Greatstaff +26% · Spellstaff +26% · Maul +34% · Light Staff +29% · Scythe +21% · เสียช่องโล่ (Block / DEF / HP จากโล่)
- อาวุธมือเดียว: มือรองใส่โล่ / ของมือรองของอาชีพ / อาวุธถือคู่ (Dagger / Axe / Knuckles) ได้ — อาวุธที่มือรองนับ ATK และ Affix 50%
- ช่องมือรองที่จางตอนถืออาวุธสองมือ = ถูกอาวุธสองมือใช้อยู่

## Property ของอาวุธ

| Property | กติกา | อาวุธที่มี |
| --- | --- | --- |
| **Reach** | ตีธรรมดาไกลขึ้น 1 ช่อง และโดนเพิ่มอีก 1 ตัวข้างหลัง (อาวุธยิง: ทะลุอีก 1 ตัว) · แลกกับ: ตีธรรมดาช้าลง 6% | หอก, ธนู, ทวน, เรเปียร์, เคียวใหญ่ |
| **Heavy** | ตีธรรมดาผลักมอน 0.25 ช่อง — มอนที่ผลักไม่ได้ (Elite / Mini-boss / Boss) เติม Break Bar แทน · แลกกับ: Dash สั้นลง 15% | ดาบสองมือ, ขวาน, ค้อน, หอกทหารม้า, ไม้เท้าศึก, ค้อนศักดิ์สิทธิ์ |
| **Finesse** | ATK ของตีธรรมดาคิดจาก STR หรือค่าเฉลี่ย AGI \+ DEX — อันที่สูงกว่า (สกิลไม่เปลี่ยน) · แลกกับ: ไม่เสียอะไร · ได้เปรียบเมื่อเน้น AGI + DEX | มีดสั้น, กริช, สนับมือ, เรเปียร์ |
| **Versatile** | มือรองว่าง = ได้ 50% ของ Heavy (ผลัก 0.125 ช่อง / เติม Break) ไม่เสีย Dash · ถือมือรองอยู่ = Block +4% และคูลดาวน์ Dash สั้นลง 15% · แลกกับ: ได้ทั้งสองแบบ เลือกตามมือรอง | ดาบ, คทาแสง |
| **Thrown** | ทุก 8 วิ ตีธรรมดาครั้งถัดไปขว้างอาวุธใส่มอนอีกตัวในระยะ 6 ช่อง ฟรี (ดึงมันเข้ามาหา) · แลกกับ: ระยะตีประชิดสั้นลง 0.25 ช่อง (อาวุธยิง: ระยะยิงสั้นลง 1 ช่อง) | หอก, ขวาน, หลาว, มีดบิน, เคียวโซ่ |
| **Loading** | ทุก 3 วิ ตีธรรมดานัดถัดไปเป็นนัดบรรจุ แรง +80% (ไม่ต้องยืนนิ่ง) · แลกกับ: ตีธรรมดานัดอื่นเบาลง 10% | หน้าไม้, คทา |
| **Channel** | แถบร่ายสั้นลง 20% · แลกกับ: ตีธรรมดาเบาลง 15% | ไม้เท้า, ลูกแก้วเวท, ไม้เท้าแสง |
| **Focus** | ร่ายสกิลต่อกันไม่ขาดช่วง (ห่างกันไม่เกิน 2.5 วิ) = สกิลถัดไปแรงขึ้น +6% ต่อชั้น (สูงสุด 3 ชั้น) · แลกกับ: เว้นช่วงไม่ร่ายสกิลเกิน 2.5 วิ = ชั้นหายหมด | กริช, ไม้เท้า, ตำรา, ไม้เท้ายาว |
| **Sweep** | ตีธรรมดากวาดรอบตัว 360° โดนเพิ่มอีก 2 ตัว · แลกกับ: ตีธรรมดาเบาลง 12% | ลูกตุ้มโซ่ |

- อาวุธแต่ละประเภทมี Property (กติกาพิเศษ) 1–2 อย่างติดมาเสมอ นอกจากค่าของมันเอง — นับเฉพาะอาวุธมือหลัก · ใช้ได้ทั้ง PvE และ PvP
- Focused: ชิ้นที่มี Affix น้อย แต่ละแถวแรงขึ้น — 1 แถว +80% · 2 แถว +35% แต่ไม่เกินค่าสูงสุดของ Tier ที่ป้ายแสดง (3 แถวขึ้นไปตามค่าเดิม · แถว Trigger ไม่คูณ)
- ตีธรรมดาไกลขึ้น 1 ช่อง และโดนเพิ่มอีก 1 ตัวข้างหลัง (อาวุธยิง: ทะลุอีก 1 ตัว) · แลกกับ: ตีธรรมดาช้าลง 6%

- ATK ของตีธรรมดาคิดจาก STR หรือค่าเฉลี่ย AGI + DEX — อันที่สูงกว่า (สกิลไม่เปลี่ยน) · แลกกับ: ไม่เสียอะไร · ได้เปรียบเมื่อเน้น AGI + DEX
- มือรองว่าง = ได้ 50% ของ Heavy (ผลัก 0.125 ช่อง / เติม Break) ไม่เสีย Dash · ถือมือรองอยู่ = Block +4% และคูลดาวน์ Dash สั้นลง 15% · แลกกับ: ได้ทั้งสองแบบ เลือกตามมือรอง
- ทุก 8 วิ ตีธรรมดาครั้งถัดไปขว้างอาวุธใส่มอนอีกตัวในระยะ 6 ช่อง ฟรี (ดึงมันเข้ามาหา) · แลกกับ: ระยะตีประชิดสั้นลง 0.25 ช่อง (อาวุธยิง: ระยะยิงสั้นลง 1 ช่อง)
- ทุก 3 วิ ตีธรรมดานัดถัดไปเป็นนัดบรรจุ แรง +80% (ไม่ต้องยืนนิ่ง) · แลกกับ: ตีธรรมดานัดอื่นเบาลง 10%
- แถบร่ายสั้นลง 20% · แลกกับ: ตีธรรมดาเบาลง 15%
- ร่ายสกิลต่อกันไม่ขาดช่วง (ห่างกันไม่เกิน 2.5 วิ) = สกิลถัดไปแรงขึ้น +6% ต่อชั้น (สูงสุด 3 ชั้น) · แลกกับ: เว้นช่วงไม่ร่ายสกิลเกิน 2.5 วิ = ชั้นหายหมด
- ตีธรรมดากวาดรอบตัว 360° โดนเพิ่มอีก 2 ตัว · แลกกับ: ตีธรรมดาเบาลง 12%

## Grip (อาวุธ + มือรอง)

- ทุกอาชีพถือได้ 5 แบบ (Grip) — อาวุธมือหลัก + ของมือรอง เปลี่ยนวิธีเล่น ไม่ใช่แค่ตัวเลข · ดู Grip ของคุณที่การ์ดอาวุธ / ของมือรอง
- ของมือรองแบบใหม่ดรอปมา 3 แบบ (เช่น ซองธนู Bodkin / Broadhead / Whistling) — ค่าสเตตเท่ากัน แต่ละแบบมีกติกาของตัวเอง · ใส่อยู่และไม่พังถึงทำงาน
- อาวุธสองมือใส่ของมือรองไม่ได้ · ธนู / หน้าไม้ถือมือเดียว แต่มือรองใส่ได้เฉพาะซองธนู
- Warrior ถือขวาน / สนับมือคู่ได้ · Scout ถือมีดที่มือรองได้ (Skirmisher) · อาวุธที่มือรองนับ ATK และ Affix 50%
- ไม้เท้าศึก (Mage) · เคียวใหญ่ / เคียวโซ่ (Soul Reaper) = ตีธรรมดาแบบประชิด · มีดบิน (Rogue) = ขว้างตีธรรมดาไกล 6 ช่อง
- เอฟเฟกต์ตอนตีธรรมดาโดน ใช้กับมอนเท่านั้น · บล็อก / หลบ / วงรอบตัวของมือรองใช้ใน PvP ด้วย
- อาวุธ Grip ใหม่แบ่งโควตาดรอปอาวุธเดิม (30% ของอาวุธที่ดรอป) · ของมือรองใหม่ดรอปเพิ่มจากโล่ / โล่เวทเดิม · ร้าน NPC ขาย T1 แบบแรก

## ของมือรองแต่ละแบบ

ของมือรองแต่ละชนิดดรอปได้หลายแบบ แต่ละแบบมีกติกาของตัวเอง

| มือรอง | แบบ · กติกา |
| --- | --- |
| **ซองธนู** | **Bodkin** — ยิงธรรมดาทะลุเพิ่มอีก 1 ตัว และไม่สน DEF ของมอน 15%<br>**Broadhead** — ยิงธรรมดาคริ → เป้าเลือดไหล 30% ATK ต่อวิ 4 วิ<br>**Whistling** — ยิงธรรมดาโดน → Hunter's Mark เพิ่มอีก 1 สแตก |
| **ถุงหิน** | **Round** — ตีธรรมดาโดน → สตันเป้า 0.5 วิ (เป้าเดิมได้อีกทุก 4 วิ · บอสไม่ติด แต่ Break Bar ขึ้น)<br>**Gravel** — ตีธรรมดาโดน → เศษกระจายโดนมอนรอบเป้าอีก 2 ตัวในระยะ 2 ช่อง (40% ของนัดนั้น)<br>**Fire** — ตีธรรมดาโดน → เป้าติดไฟ 15% ATK ต่อวิ 3 วิ |
| **โล่หอคอย** | **Bastion** — ยืนนิ่ง 0.6 วิ ขึ้นไป → Block จากอุปกรณ์ ×2 · ขยับตัวแล้วกลับเป็นปกติ<br>**Rampart** — ดาเมจเวทที่มาจากด้านหน้า (ภายใน 70° ของทิศที่หัน) ลดลง 30% — เวท Block ไม่ได้<br>**Aegis** — Block สำเร็จ → เพื่อนปาร์ตี้ที่ใกล้ที่สุดในระยะ 8 ช่องได้เกราะ 6% ของ HP เขา (ทุก 2 วิ · ไม่มีปาร์ตี้ = ไม่มีผล) |
