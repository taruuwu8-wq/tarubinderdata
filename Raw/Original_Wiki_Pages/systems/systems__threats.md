- ลักษณะมอนของแมพ = นับจากมอนทั่วไป \+ Elite ทุกตัวที่เกิดจริงในแมพ (ไม่นับ Mini-boss / บอส) — ขึ้นป้ายเมื่อมีตั้งแต่ 25% ขึ้นไป
- เกราะหนา = DEF สูงกว่ามอนเลเวลเดียวกันทั่วไป +40% ขึ้นไป · ต้านเวท = MDEF สูงกว่า +80% ขึ้นไป
- เกราะหนา: DEF สูง: ตีกายภาพเข้าน้อย — สายเวท / ทะลุเกราะได้เปรียบ
- ต้านเวท: MDEF สูง: เวทเข้าน้อย — สายกายภาพได้เปรียบ
- ยิงไกล: ยิงจากระยะไกลแล้วถอยหนี — สายยิงไกล / พุ่งตัวไล่ทัน
- ร่ายท่า: ร่ายวงอันตราย / ยิงท่าใส่จุดที่คุณยืน — เดินหลบได้ ระวังตอนยืนนิ่ง
- ฮีลกันเอง: เลือดต่ำแล้วฮีลตัวเองและพวกรอบตัว — ตีหมู่แรงๆ หรือรีบปิดทีละตัว
- ฝูง · เรียกพวก: เห็นคุณแล้วเรียกพวกมารุม — สายตีหมู่ / ทนได้เปรียบ
- เข้ามาตีก่อน: วิ่งเข้ามาตีก่อนโดยไม่ต้องยั่ว — เตรียมยา / ความทน
- ซุ่มรอ: ซ่อนตัวรอแล้วโผล่มาตีเมื่อเดินผ่าน
- แพ้ / ต้านธาตุ = ธาตุที่มอนในแมพแพ้หรือต้าน (Infusion ตีตัวที่แพ้ +20% · ตัวที่ต้าน −15%)
